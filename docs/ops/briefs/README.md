# Routine output

Each routine run writes its report here as
`YYYY-MM-DD-<routine>.md` — for example `2026-08-07-daily-brief.md`. A routine
that runs more than once a day appends a `-2`, `-3` suffix rather than
overwriting: two runs found two different states, and both are evidence.

**These files are outputs, not sources.** When a brief disagrees with
`../TASK-REGISTER.md`, the register is controlling — that is the source
hierarchy in `docs/DD84-OPERATIONS-AGENT.md` §3. A brief is a snapshot of what
was visible at one moment through whichever connectors happened to be reachable.

Briefs are kept rather than pruned. A run that reports "Stripe not available
this run" is the record that proves a figure was missing rather than zero, and
that is worth more later than the tidiness of deleting it.

Nothing has been written here yet — no routine has run against a live connector.
